
# Learning Tracker Mini

## Overview

Learning Tracker Mini is a Python application designed to track and analyze study sessions.
This project was created as part of my Python learning journey to practice Object-Oriented Programming (OOP), file handling, and data processing.

## Features

- Add study sessions
- Calculate total study time
- Find the longest study session
- Calculate average study time
- Count the total number of study sessions
- Save study sessions to a text file
- Load study sessions from a text file

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- File Handling
